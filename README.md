# DevDesk — macOS GitHub Client

A production-grade macOS application built with SwiftUI that demonstrates
modern macOS architecture, async/await networking, and SwiftData persistence.

## Features
- Sidebar-based macOS navigation (NavigationSplitView)
- GitHub API integration using async/await
- Clean MVVM architecture
- Offline persistence using SwiftData
- Error handling & loading states
- macOS menu commands & keyboard shortcuts

## Tech Stack
- Swift 5.9+
- SwiftUI (macOS)
- MVVM Architecture
- URLSession + async/await
- SwiftData
